# Comprovantes do acampamento

Fotos dos cupons/notas fiscais para comprovar os gastos do acampamento.

| Pasta | O que colocar |
|---|---|
| `bruno/` | Fotos dos cupons que o Bruno enviou |
| `dogão/` | Fotos dos cupons que o Dogão enviou |
| `planilha/` | A planilha de gastos (.xlsx) que será conferida |

## Próximos passos (depois que as fotos e a planilha forem enviadas)

1. Otimizar as fotos (recorte, correção de perspectiva, contraste) para os comprovantes ficarem legíveis.
2. Gerar um PDF para impressão, separado por pessoa (Bruno / Dogão).
3. Ler cada comprovante (data, estabelecimento, valor) e cruzar com a planilha:
   - linhas encontradas nos comprovantes → célula pintada de **amarelo** (conferida);
   - lançamentos sem comprovante e comprovantes sem lançamento → listados na seção **Pendências** abaixo da tabela.
